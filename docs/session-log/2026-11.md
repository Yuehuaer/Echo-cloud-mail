### 经验记录
- [Cloudflare] Email Routing 规则的 `all` matcher 被锁定（2020 Invalid rule operation，连 DELETE 都失败），必须用 `literal` matcher + 通配符 `*@kechox.com` 才能建 worker 动作规则。
- [Cloudflare] Worker custom domain 用 `PUT /accounts/{acc}/workers/domains` 绑定（POST 报 10405）；手动 API 加的绑定会被 wrangler deploy 冲掉，必须写进部署配置。
- [Cloudflare] `/api/init` 是幂等 migration，不清数据；它用 D1 配置 refresh 覆盖 KV，所以改配置必须 D1 + KV 双写。
- [Cloudflare] D1 字段 `resend_tokens`（下划线），KV `setting:` key 里是 `resendTokens`（驼峰），不要查错字段。
- [环境] Windows Git Bash 下 `/tmp` 不可用，用工作区临时文件；`jq` 未安装，用 `python -c` 处理 JSON。
- [安全] 公开仓库不要提交 `.workbuddy/memory/`（含运维细节），本仓库 .gitignore 已排除。
